# 📦 Factuur Studio

Een krachtige WordPress-plugin om voorbeeldfacturen te genereren in PDF + Peppol XML (UBL). Ontwikkeld voor demonstraties en integraties met Octopus boekhoudsoftware.

## 🚀 Functionaliteiten

- ✅ Verkoop- en aankoopfacturen genereren
- ✅ PDF + XML (Peppol BIS 3.0 + EN16931)
- ✅ Verzenden per e-mail
- ✅ ZIP-downloads
- ✅ Logging en beheer
- ✅ Elementor-widgets voor frontend integratie

## 📁 Pluginstructuur

- `includes/` – Factuurgeneratie & handlers
- `templates/` – Admin UI templates
- `assets/` – CSS en JS
- `logs/` – E-mail logs
- `admin/` – Extra admin pagina’s zoals log-view
- `octopus-facturatiegenerator.php` – Plugin hoofdbestand

## 🛠️ Installatie

1. Clone deze repo naar je `wp-content/plugins/` map
2. Activeer via WordPress admin
3. Ga naar **Factuur Studio** in het menu
